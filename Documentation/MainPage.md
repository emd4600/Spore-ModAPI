@mainpage

The <b>Spore %ModAPI SDK</b> allows you to create C++ mods for Spore. These mods are compiled into <tt>.dll</tt> files,
that can then be used by the <b>[%ModAPI Launcher Kit](https://launcherkit.sporecommunity.com/)</b> or <b>[SporeModLoader](https://github.com/Rosalie241/SporeModLoader)</b> to inject them into Spore.

Instructions about download, installation and updating can be found [in this tutorial](_installation.html).

The source code can be found at the [GitHub repository](https://github.com/Spore-Community/Spore-ModAPI). It also includes the source code
of 3 real mods made with the %ModAPI SDK:
 - [EnhancedColorPicker](https://github.com/Spore-Community/Spore-ModAPI/tree/master/Projects/Example%20Projects/EnhancedColorPicker)
 - [GmdlExport](https://github.com/Spore-Community/Spore-ModAPI/tree/master/Projects/Example%20Projects/GmdlExport)
 - [ModCreatorKit](https://github.com/Spore-Community/Spore-ModAPI/tree/master/Projects/Example%20Projects/ModCreatorKit)
